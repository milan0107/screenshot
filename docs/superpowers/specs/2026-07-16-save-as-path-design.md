# 截图另存为设计

## 目标

长截图生成完成后，每次都打开 Chrome 的系统“另存为”窗口，让用户选择保存文件夹并可修改文件名。

## 行为

- 截图选择、滚动、拼接和 PNG 生成流程保持不变。
- 下载截图时向 `chrome.downloads.download` 传入 `saveAs: true`。
- “另存为”窗口沿用当前自动生成的 PNG 文件名作为默认文件名。
- 用户可在窗口中选择路径、修改文件名或取消保存。
- 用户取消“另存为”不应被显示为截图生成失败；截图任务已经完成，下载取消由 Chrome 处理。

## 实现边界

- 只修改后台截图控制器发起下载时的参数。
- 不增加设置页面，不记忆用户选择的目录，也不引入网页文件系统 API。
- 保留现有下载权限与消息流程。

## 测试

- 更新截图控制器测试，断言下载参数为 `saveAs: true`。
- 运行截图控制器测试及完整测试套件，确认截图拼接、内部滚动容器和现有错误处理没有回归。
