# 选区操作条右侧定位设计

## 目标

在用户完成拖拽选区后，将「确认截图 / 重新选择 / 取消」操作条整体显示在选区右侧，而非选区下方。

## 定位规则

1. 操作条默认位于可见选区的右边缘之外，间距 8px。
2. 操作条的垂直中心与可见选区的垂直中心对齐。
3. 右侧无法完整容纳时，操作条移至选区左侧，仍保持 8px 间距。
4. 若左右两侧都无法完整容纳，最终坐标钳制在视口 8px 安全边距内，确保三个按钮保持可见、可点击。

## 不变项

- 按钮的文字、顺序及回调保持不变。
- 鼠标拖拽、重新选择、取消和 Escape 取消的行为保持不变。
- 选区自身仍按当前逻辑裁剪到滚动容器或页面视口。

## 验收与测试

- 右侧空间足够时，操作条的左边缘等于选区右边缘加 8px。
- 右侧空间不足而左侧足够时，操作条右边缘等于选区左边缘减 8px。
- 两侧都不足时，操作条保持在视口边界内。
- 现有确认、重新选择和取消按钮事件仍能正常触发。
