# 菜单出现在鼠标附近 Design

> 部分已被 `2026-07-19-post-capture-menu-design.md` 修订：菜单只在截图完成后出现，格式选择改在完成后决定，复制/保存走独立消息。本文保留其仍适用的设计细节。

## 背景

画质/格式选项和操作按钮原本分处两处：

- 「画质 / 格式」条固定在视口顶部居中，点击扩展图标后与鼠标位置相距很远，需要额外移动；
- 「确认截图 / 重新选择 / 取消」操作条按选区右边缘定位（见 `2026-07-16-selection-controls-right-design.md`），选区较大时离鼠标很远。

## Goal

把两组菜单合并为一个浮层菜单，并在它「弹出来」的时候出现在鼠标附近。

## User Flow

1. 点击扩展图标进入选区模式 → 菜单在拿到第一个指针位置之前**保持隐藏**；鼠标一进入页面就**首次出现在指针旁**，不会先闪现在视口顶部居中。
2. 菜单跟随指针移动，指针靠近菜单时停止跟随（否则菜单会不断从光标下跑开而无法点击）；指针远离后继续跟随。
3. 菜单与指针之间保留 8px 间隔，指针本身不会落在菜单上，因此可以直接从指针位置按下开始框选。
4. 按下鼠标开始拖拽 → 菜单隐藏，避免遮挡框选区域。
5. 松开鼠标 → 菜单重新出现在释放点附近，并展开 `确认截图 / 重新选择 / 取消`；已有选区后移动鼠标不再让菜单跟随。
6. 切换画质会重置选区（布局变化），菜单恢复跟随状态；切换格式不影响选区。

## Architecture

- `createSelectionUI` 把原 `.mode` 与 `.controls` 合并为单个 `.panel`，内部两行：`画质 [普通][高清] │ 格式 [PNG][JPG]` 与操作行 `.actions`（选区完成后才展开）。单浮层避免了两个面板同时锚定在指针处互相遮挡。
- 面板初始 `display: none`，只有 `placePanel()` 成功定位后才显示（`placed` 标记），保证用户看到的第一次出现就在指针旁；`setDragging(false)` 在未定位时也保持隐藏。
- 新增纯函数 `positionPanelAt(point, panelSize, viewportSize)`：优先指针右下，越界翻转到左/上，最终夹紧到 8px 安全边距。取代原 `positionControls()`。
- 面板定位：`placePanel(point, {force})` 测量自身尺寸后调用 `positionPanelAt`；当指针落在面板外扩 `FOLLOW_REST_ZONE = 24px` 的静止区内时跳过重定位。
- `setComplete(complete, point)` 用 `force: true` 定位，保证拖拽结束后菜单一定出现在释放点附近（即使释放点落在旧位置的静止区内）。
- `setDragging(dragging)` 控制拖拽期间隐藏；`reset()` 只收起操作行与提示，不移动菜单。
- 选择控制器新增 `state.pointer`，在未拖拽且无选区时于 `pointermove` 更新菜单位置；`pointerup` 传释放点；`pointercancel` 恢复菜单显示。

## Constraints

- 菜单的显示/隐藏不影响遮罩接收拖拽：菜单只占自身区域，且与指针保持间隔。
- 不改变按钮文案、顺序与回调，不改变框选、自动滚动、取消与 Esc 行为。
- 菜单不得覆盖选区绘制层（`.selection`），两者互不影响。

## Testing

- `positionPanelAt` 单测：默认右下、右侧不足翻转左侧、下方不足翻转上方、右下都不足、超尺寸面板、贴边指针、短视口高面板、与指针的 8px 间隔。
- UI 测试：面板结构（画质行 + 操作行）、跟随指针、靠近时停止跟随、远离后继续跟随、拖拽隐藏、松手后按释放点定位并展开操作行。
- 控制器测试：`pointermove` 在无选区时移动菜单、拖拽期间不移动、`pointerup` 以释放点展开操作行、已有选区后移动鼠标不再跟随。
